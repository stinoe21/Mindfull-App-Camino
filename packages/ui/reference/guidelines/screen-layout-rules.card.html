Screen layout rules

Rules, not suggestions — every MIND screen follows them.

  1. Gradient is the page background. Weather gradient behind everything; no text directly on it on standard screens.
  2. One beige sheet per screen. Radius 20, inset by an 8px margin left/right/bottom, top at 56 — a thin ring of gradient stays visible.
  3. Sheet padding 20. Only a shelf bleeds to the edge, with bleed equal to the sheet padding.
  4. Cards pad 18/20, internal gap 6. One shape (radius 16) recolored by tone; grid rows ≥120, shelf cards 172×152.
  5. Every collection has a section header. Serif title, optional note, optional text action right. Sections 28 apart, header-to-content 12.
  6. Shelf or grid, never both. Shelf for open-ended collections, grid (2 equal columns, gutter 12) for finite sets. No mosaic spans.
  7. Rhythm over variety. Title → one lead card → sections. Vary tone and section type, never card shape or padding.
  8. 4px scale only (4/8/12/16/20/24/28/32/40/48), beyond the fixed values above.
