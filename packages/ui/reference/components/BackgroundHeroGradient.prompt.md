Soft full-bleed weather-tinted gradient, sits behind the top of a screen (480px tall) for moments that celebrate a personal check-in result (confirmation, weather outcome). 

```jsx
<BackgroundHeroGradient state="zonnig" style={{position:"absolute",top:0,left:0,width:402,height:480}} />
```

Sibling `BackgroundHeroBand` is the shorter (200px) neutral version used on every standard interior screen (dashboard, lists, forms) — same artwork, cropped band instead of full gradient wash.
