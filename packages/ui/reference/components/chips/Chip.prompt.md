Pill-shaped topic tag — browsing aid for Naslagwerk topics ("Slaap", "Stress") and challenge categories ("RUST", "BEWEGING").

```jsx
<Chip label="Stress" />
<Chip label="Somberheid" active />
```

Two documented roles: a **browsing aid** (topic/category tag, where `active` means "currently filtered/viewing"), and a **multi-select form control** — `/App-flow-v1/8 · Systeembreed` specifies "Keuze-chips (multi-select)" for the Voorkeuren step, so `active` is a legitimate persisted selection state there.
