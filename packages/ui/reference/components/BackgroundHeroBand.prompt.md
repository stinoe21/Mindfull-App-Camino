200px neutral hero band — the default top-of-screen backdrop behind the rounded canvas on nearly every interior screen (dashboard, challenges, naslagwerk, profile, forms).

```jsx
<BackgroundHeroBand state="default" style={{position:"absolute",top:0,left:0,width:402,height:200}} />
```

Use `BackgroundHeroGradient` instead for full-bleed celebratory/result moments.
